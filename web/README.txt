OUTPOST ZERO - browser prototype
Open index.html in any modern browser (double-click works, no server needed),
or host this folder on any static web host. Portrait, touch-friendly.
Drag left/right to steer and shoot the numbered gates until they turn blue, then run through.
Shield button = Rook's Shield Wall. Tap PLAY to start (enables sound).
?demo in the URL = auto-steer attract mode.
