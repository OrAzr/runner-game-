# Outpost Zero (Unity draft)

A first playable draft of the battle run: Rook's squad runs up a clean road, you steer through
+/x gates and shootable counter gates (a red number such as -20 that climbs with each bullet and
turns blue past zero), shoot crates for temporary weapons, fight sparse zombie groups and finish with a boss.
All art is placeholder low-poly geometry built from code. All audio is original and synthesized.

## Open & play
1. Install **Unity Hub** and **Unity 2022.3 LTS** (Unity 6 should also work), with the
   **Android Build Support** and/or **iOS Build Support** modules.
2. Unity Hub → *Add* → *Add project from disk* → pick this `OutpostZero` folder.
   (The first import builds `Library/`, which takes a few minutes.)
3. The main scene is built automatically the first time the project opens. To rebuild it at any time:
   menu **Outpost Zero → Build Main Scene**. It creates `Assets/Scenes/Main.unity`, wires the audio
   clips, adds the scene to Build Settings and sets portrait orientation + bundle id.
4. Open `Assets/Scenes/Main.unity`, set the Game view to a portrait size (e.g. 1080×1920) and press **Play**.

Controls: drag left/right with the mouse (or touch on device). Arrow keys / A-D also steer, Space = Shield Wall.

> Input uses the legacy Input Manager (Unity's default for a new project). If your Unity 6 install
> switched *Project Settings → Player → Active Input Handling* to "Input System Package (New)",
> set it to **Both**.

## Code map (`Assets/Scripts`)
| Area | Files |
|---|---|
| Core | `GameManager` (state machine, win/lose), `LevelConfig` (gates, zombie groups, crates, boss – tweak the run here), `CameraFollow`, `Prims` (code-built geometry, materials, 3D labels) |
| Squad | `SquadController` (count, forward motion, gates, losses), `Formation` (sunflower formation), `SteeringInput` (touch + mouse drag), `Soldier`, `HeroRook` (starting hero, Shield Wall special) |
| Combat | `AutoShooter` (fire rate scales with squad size, timed weapon pickups), `Projectile` (pooled tracers), `Weapons` (rifle / shotgun / flamethrower stats), `Damageable`, `Effects` (code-built particles) |
| Enemies | `Zombie`, `Boss` |
| World | `Gate` (+N, xN, and shootable `#-20` counters), `WeaponCrate`, `LevelBuilder` |
| UI | `GameUI` (runtime uGUI: menu, HUD, boss HP bar, shield button, end screen, safe area) |
| Audio | `AudioManager` (voice pool, throttling, music + flamethrower loops) |
| Editor | `Assets/Editor/OutpostSceneBuilder.cs` |

Works with the Built-in render pipeline; `Prims` also picks URP shaders if you switch to URP later.

## Build for Android
1. *File → Build Settings → Android → Switch Platform*.
2. *Player Settings*: bundle id is preset to `com.outpostzero.game` (change it to your own), min API 24.
   For Google Play: *Other Settings → Scripting Backend = IL2CPP*, *Target Architectures = ARM64*,
   and create a keystore under *Publishing Settings*.
3. *Build* (APK for testing) or enable *Build App Bundle (Google Play)* for an `.aab`.

## Build for iOS

The cloud TestFlight pipeline is [docs/IOS_BUILD.md](../../docs/IOS_BUILD.md). It exports an Xcode project with GameCI and uploads an IPA to TestFlight. Signing certificates are created in CI, so that path does not need a Mac.

A local Xcode build still works if you have a Mac:

1. *File → Build Settings → iOS → Switch Platform → Build*. This writes an Xcode project.
2. Open the `.xcodeproj` in Xcode, choose your Team under *Signing & Capabilities*, and run it on a device
   or *Product → Archive* to upload to TestFlight/App Store.

## Audio
`Assets/Audio/*.wav` are generated by `audio-src/synth.py` (numpy/scipy, no samples). Re-run it to tweak sounds.

## Weapon models
`Assets/Resources/Models/Weapons/{rifle,shotgun,flamethrower}.{fbx,png}` were generated with [Meshy AI](https://www.meshy.ai/)
and are loaded at runtime via `Resources.Load`; `WeaponVisual` falls back to the code-built primitive gun if a model is missing.
